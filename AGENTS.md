# AGENTS.md

## What this repo is

This is the **M@TE (Model, Topography, Tectonics & Earth dynamics) model template**. It is a GitHub template repository — individual model repos are created from it, not forked. Automation runs entirely through GitHub Actions triggered by issues and labels, not via local developer commands.

## Repository structure

```
model_code_inputs/     # Model code and inputs (populated per model)
model_output_data/     # Gitignored except README.md; data lives on NCI
.metadata_trail/       # Holds nci_iso.csv and other metadata artifacts
.website_material/     # Static assets (graphics, etc.) kept in the repo
  assets/
  graphics/
CITATION.cff           # Auto-generated by workflow; do not edit by hand
ro-crate-metadata.json # Central metadata file (RO-Crate format); expected at repo root
.github/scripts/       # Python automation scripts (Python 3.10)
.github/workflows/     # One CI workflow (see below)
```

## Critical file: `ro-crate-metadata.json`

- **Expected at repo root only** — `"ro-crate-metadata.json"` is the single source of truth.
- `update_doi.py` loads this file, uses the `rocrate` library to update `identifier` (root, `model_inputs`, `model_outputs`) and `creditText`, then commits it back.
- `CITATION.cff` is auto-generated from the RO-Crate by `parse_utils.ro_crate_to_cff()`; editing it manually will be overwritten on publish.

## Workflows

### `copy-files.yml` — triggered by issue label `model published`
Runs `update_doi.py`: reads DOI from issue body (`### -> doi` field), validates it, updates `ro-crate-metadata.json` + `CITATION.cff` + `.metadata_trail/nci_iso.csv`. Also cleans up `.gitkeep` placeholder files.

## GitHub App authentication

`copy-files.yml` uses a GitHub App (`APP_ID` var + `APP_PRIVATE_KEY` secret) via `actions/create-github-app-token` to write back to the model repo.

## Python scripts

- Python **3.10**, dependencies: `pygithub==2.2.0`, `rocrate`, `pyyaml`.
- Install: `pip install -r .github/scripts/requirements.txt`
- Scripts read all config from **environment variables**, not CLI args.
- `parse_utils.py` and `file_utils.py` are local imports used by `update_doi.py`; run scripts from `.github/scripts/` or ensure the directory is on `PYTHONPATH`.
- See `.github/scripts/SCRIPTS_REFERENCE.md` for a full description of every file and function.

### Script inventory

| File | Role |
|---|---|
| `update_doi.py` | Workflow entry point. Validates DOI from issue, updates `ro-crate-metadata.json`, `CITATION.cff`, and `.metadata_trail/nci_iso.csv` via GitHub API. |
| `parse_utils.py` | Pure utilities: `extract_doi_parts()`, `format_citation()`, `ro_crate_to_cff()`. Uses `rocrate` library. No GitHub calls. |
| `file_utils.py` | Pure utility: `update_csv_content()`. No GitHub calls. |
| `request_utils.py` | Utility: `check_uri()`. Currently unused. |

## Gitignore quirk

`model_output_data/*` is ignored except `model_output_data/README.md`. Actual output data is not stored in git — it lives on NCI (http://dx.doi.org/10.25914/yrzp-g882).

## `.gitkeep` files

Placeholder `.gitkeep` files exist in empty directories. The `copy-files.yml` workflow automatically removes them once real content is present in the same directory.

## Issue template

`publish_model.yml` creates an issue titled "Publish model" with label `model published` pre-applied. The body field `-> doi` is parsed by regex `### *(?P<key>.*?)\s*[\r\n]+(?P<value>...)` in `update_doi.py`. DOI must match `10\.[0-9]+/[^ \s]+`.
